# 发票 → 报销单

把一堆电子发票丢给 AI，回答两个问题，拿走一个能直接打印的 Word。

不用懂代码，不用装软件，不用手动填金额。

---

## 你会得到什么

一个 Word 文件，打开就是这样：

```
第 1 页      费用报销单（名称、摘要、金额、大写金额都填好了，只剩签字手写）
第 2 页      发票 1  ／  发票 2
第 3 页      发票 3  ／  发票 4
第 4 页      发票 5  ／  发票 6
...
```

直接 Ctrl+P 打印，一页 A4 放两张发票，裁开就能贴单。

## 三步搞定

### 第一步：装进你的 AI

把下面这句话复制给你的 AI（WorkBuddy / Codex / Claude Code / Cursor 都行），**把链接一起发过去**：

```
帮我安装这个 skill：https://github.com/MrVoler/fapiao-skill
```

它会自己下载并放到正确的位置。各家默认目录是：

| 你用哪个 AI | skill 放在哪 |
|---|---|
| WorkBuddy | `~/.workbuddy/skills/fapiao-skill` |
| Codex CLI | `~/.codex/skills/fapiao-skill` |
| Claude Code | `~/.claude/skills/fapiao-skill` |
| Cursor / Copilot / Gemini CLI 等 | 遵循 [Agent Skills 标准](https://agentskills.io)，让 AI 自己判断 |

装完可以问它一句「你会做发票报销吗」，它答得上来就说明装好了。

> 装好后建议新开一个对话，这样它才能读到新装的能力。

**如果 AI 装不上**，就手动来：把仓库下载成 zip，解压后把整个 `fapiao-skill` 文件夹拖进上表对应的目录，重开对话即可。

### 第二步：把发票发给它，说一句话

发票可以是**压缩包**，也可以是一个**装满 PDF 的文件夹**，无所谓几个，一起发过去，然后说：

```
帮我做报销
```

它看完发票会告诉你「一共 12 张，合计 386.50 元」，然后只问你两个问题：

> **AI**：这次报销的**费用名称**填什么？
> **你**：交通费
>
> **AI**：**摘要**（备注）写什么？
> **你**：10 月市内打车
>
> **AI**：好了，文件在 `报销单-交通费-20261109.docx`

就这两句，没有第三个问题。

### 第三步：拿走文件

它会把 Word 放在**发票旁边**，名字是 `报销单-交通费-20261109.docx`（费用名称 + 日期）。

顺带还会生成一个同名的 PDF，不想再调格式可以直接用 PDF 打印。

**打印设置：**

- 纸张 A4、纵向
- 缩放选「无缩放 / 100%」
- **不要选双面打印**——第 1 页背面就是第 2 页，裁开容易配错

**报销人和经理审批是空着的**，这是故意的，留给你手写。

## 它只问你两个问题，为什么

因为其他东西都有标准答案，问了你也不知道怎么答：

| 你可能会担心的事 | 它怎么处理 |
|---|---|
| 金额填多少 | 自动从发票里读，并且逐张核对过 |
| 金额大写怎么写 | 自动转，`386.50` → `叁佰捌拾陆元伍角整` |
| 附单据写几张 | 数出来的，就是发票张数 |
| 日期填哪天 | 今天 |
| 报销单长什么样 | 自带一个通用模板；你有公司模板就发给它 |
| 明细要不要按平台分行 | 默认合成一行，最省地方 |

**费用名称**和**摘要**它猜不出来，填错了整张单子要重做，所以才问你。回答时记住：

- **费用名称** = 这笔钱报在哪个科目，写单位财务认可的叫法（交通费、差旅费、办公用品、软件订阅费）
- **摘要** = 「什么时候 + 干了什么」，写清楚比写得短重要（「10 月市内打车」比「打车」好）

## 常见问题

**Q：我的发票是一个文件夹，不是压缩包，能用吗？**
能。直接把文件夹发给它，或者告诉它文件夹在哪。

**Q：发票是手机拍的照片 / 截图，能用吗？**
不能。需要的是**电子发票 PDF**（在打车/购物 App 里开票后下载的那种）。图片没有金额文本，读不出来。

**Q：压缩包有密码怎么办？**
先自己解压，再把解压后的文件夹给它。

**Q：我公司有自己的报销单模板。**
把模板文件一起发给它，说「用我这个模板」，它会换掉自带的。

**Q：算出来的金额和我预期不一样。**
它会逐张列出金额和发票号，让你核对是哪张有问题，不会自己挑一个数糊弄过去。

**Q：能不能一页放 3 张？**
能，跟它说「一页放三张」即可（对应 `--per-page 3`）。

**Q：打印出来字太小 / 边缘被切了。**
先看 `报销中间文件/预览/` 里的图片，那里就是实际打印效果；有问题告诉它重新排。

**Q：行程单要不要一起打印？**
默认不打印。行程单是行程明细，不是发票，混在一起容易被财务退回。单位要求附的话跟它说一声。

**Q：我的发票会被上传到网上吗？**
不会。所有处理都在你自己电脑上完成，仓库里只有代码和一张空白模板，不含任何人的发票。

## 它背后做了七件事

给好奇的人：

| 步骤 | 干什么 | 为什么必须 |
|---|---|---|
| 1 汇集 | 解压、把发票和行程单分开、去重 | 两者常混在一个包里，容易打错 |
| 2 核价 | 从发票里的结构化数据读金额，再和文件名对一遍 | 发票 PDF 里中文是图片化的，读不出来 |
| 3 转图 | 转成 300 DPI 高清图，裁掉白边 | 直接插 PDF 打印会模糊 |
| 4 排版 | 每页 A4 两张，行高锁死 | 不锁行高就会串页、裁切 |
| 5 填单 | 名称、摘要、金额分格、大写、张数 | 分格填错一位整张单作废 |
| 6 合并 | 报销单页 + 发票页拼成一个文件 | 打印时不用分两次 |
| 7 校验 | 用 Word 实测页数，逐页数图片 | 只看公式不算完成，要真能打印 |

## 给想改代码的人

```
fapiao-skill/
├── SKILL.md                  给 AI 看的说明书（交互规则、默认值）
├── scripts/
│   ├── pipeline.py           一条命令跑完七步
│   ├── 01_collect.py         解压、分类、去重
│   ├── 02_amounts.py         取金额、交叉核对、出汇总表
│   ├── 03_render.py          PDF → 300 DPI 图，裁白边
│   ├── 04_build_invoice_docx.py  每页两张排版
│   ├── 05_fill_form.py       填报销单（分格 / 大写 / 张数）
│   ├── 06_merge.py           合并（表格深拷贝 + 图片关系重绑）
│   └── 07_verify.py          实测页数 + 导出 PDF
├── assets/费用报销单模板.docx  自带的两联空白模板
└── references/               流程细则、模板结构、踩坑记录
```

单独跑：

```bash
python scripts/pipeline.py --src 发票.zip --fee "交通费" --summary "10 月市内打车"
```

依赖：

```bash
pip install python-docx pymupdf pillow pypdf pywin32
```

- 金额取数电票 XML 的 `TotalTax-includedAmount`，文件名只用于校验
- 合并没用 Word COM 的 `InsertFile`（文档首块是表格时会插进单元格），改成深拷贝表格 + 重绑 `a:blip`
- `07_verify.py` 用 pywin32 驱动本机 Word 统计真实分页，非 Windows 会跳过并提示人工确认
- 换公司模板只要满足「表头含费用名称/摘要 + 金额分格含分角元」，脚本按表头文字定位，不写死行列

细节都在 `references/`：`workflow.md`（判定标准）、`template-structure.md`（表格结构）、`pitfalls.md`（八个真实踩过的坑）。
